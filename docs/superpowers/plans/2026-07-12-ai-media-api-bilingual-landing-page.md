# Bilingual AI Media API Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a conversion-focused `/ai-media-api` acquisition page in both Default and Classic themes, with complete English and Chinese UI, correct theme-specific routes, SEO metadata, and Umami CTA tracking.

**Architecture:** Each theme owns a small landing-page feature with the same product content and analytics contract but native components and routing. Pure landing helpers hold CTA destinations, allowed analytics locations, code samples, and localized metadata so Node's native test runner can verify behavior without adding dependencies. All visible copy remains in the existing i18next locale files; English is the source key, Chinese is translated, and other currently enabled locales receive explicit English fallback values for this page.

**Tech Stack:** React 19 + TypeScript + TanStack Router + Tailwind (Default); React 18 + JavaScript + React Router + Semi Design/Tailwind utilities (Classic); i18next; Node native test runner; npm; Docker Compose.

## Global Constraints

- Read and follow `docs/superpowers/specs/2026-07-12-ai-media-api-landing-page-design.md` before editing.
- Public route is exactly `/ai-media-api` in both themes; do not replace or redesign `/`.
- Version one supports English and Chinese. English is default; Default `zh` and Classic `zh-CN`/`zh-TW` use the approved Simplified Chinese copy.
- Default CTA destinations: logged out `/sign-up`, logged in `/playground`.
- Classic CTA destinations: logged out `/register?source=ai-media-api`, logged in `/console/playground`.
- Primary CTA event is exactly `get_started_clicked`; allowed `location` values are `ai_media_hero`, `ai_media_pricing`, and `ai_media_final`.
- Do not add dependencies, backend/database changes, a pricing API request, fake metrics, testimonials, provider logos, or hard-coded model prices.
- Use existing analytics helpers. Analytics failure must never block navigation.
- Use npm only. Do not run `bun`, `bunx`, or change Classic's `react-icons@5.3.0` pin.
- Preserve all new-api and QuantumNous references and copyright headers.
- Do not bulk-delete files.
- Keep both themes synchronized in behavior, copy, analytics, accessibility, and responsive layout.
- Do not commit, push, or deploy feature code before the user verifies the local Docker build. Leave implementation changes uncommitted and report them for review.
