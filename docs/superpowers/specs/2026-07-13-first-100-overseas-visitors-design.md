# First 100 Overseas Visitors Campaign Design

## Status

Approved for execution on 2026-07-13.

## Objective

Acquire the first 100 qualified external visitors for `https://vancine.com/ai-media-api` and learn which message produces registrations and successful first API requests.

## Audience

- Indie developers and small SaaS teams integrating AI video, image, speech, text, or 3D generation.
- Developers actively comparing Seedance API access.
- Builders who value one account, one API key, unified billing, and a test credit before funding.

## Recommended Approach

Use high-intent, founder-transparent distribution instead of mass posting:

1. Reply to two existing Reddit discussions where developers explicitly ask for Seedance API options.
2. Publish one original founder post in `r/SideProject` asking for integration feedback.
3. Publish one concise launch post on X.

Do not post identical copy across communities. Do not publish to unrelated subreddits or send unsolicited direct messages.

## Product Claims

Allowed:

- One API for supported video, image, speech, text, and 3D models.
- Current examples include Seedance, Seedream, Doubao TTS, and Qwen Image.
- New accounts receive `$1` in free credit.
- No credit card is required to start.
- Live documentation and pricing are public.

Forbidden:

- Cheapest, official partner, unrestricted, unlimited, guaranteed uptime, worldwide availability, or safety-filter bypass claims.
- Unverified per-second price comparisons.
- Pretending to be an independent customer.

Every Reddit message must disclose that the author is building Vancine.

## Success and Stop Rules

- Primary target: 100 external landing visitors.
- Landing page to primary CTA target: at least 8%.
- Watch registrations, successful Playground requests, and checkout starts.
- If a community removes a post, do not repost it there.
- Respond to genuine technical questions, but do not argue, mass reply, or send unsolicited DMs.
- Review results after 24 hours and again after 72 hours.
